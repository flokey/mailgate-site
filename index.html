mailgate

A self-hosted, read-only Gmail filtering proxy that lets a personal AI agent see only safe, filtered email.

What it does

mailgate is a small program that a person runs on their own computer or home server. It connects to one Gmail mailbox with the read-only scope https://www.googleapis.com/auth/gmail.readonly and gives a personal assistant agent access to a filtered view of that mailbox through the Model Context Protocol (MCP).

Before any message reaches the agent, mailgate:

  • only considers messages carrying a specific Gmail label that the owner applies;
  • blocks security and financial mail (verification codes, password resets, sign-in alerts, banks, payment providers);
  • only allows senders on the owner's allowlist, such as shops, airlines and hotels;
  • converts the message to plain text and redacts codes, links, email addresses, phone numbers, ID numbers and card numbers;
  • drops attachments.

The agent uses this to keep track of purchases, bookings, discounts and appointments. mailgate cannot send, delete, or modify email.

Who it is for

mailgate is a personal, non-commercial project for the developer and their family. It is not a hosted service: there is no server operated by the developer, and no data is sent to the developer. Each installation runs under the control of the mailbox owner.
