Privacy Policy

Effective 10 November 2026

mailgate is a self-hosted program. It runs on hardware controlled by the person who installs it (the "owner"), and it talks to Google's Gmail API directly from there. The developer of mailgate does not run any server for it and never receives any of your data.

Data mailgate accesses

mailgate requests a single Google OAuth scope: https://www.googleapis.com/auth/gmail.readonly. If Google grants any additional scope, mailgate refuses to save the token. With this scope mailgate reads message headers (such as sender, recipient, subject, date and authentication results), labels, and message bodies of the one Gmail account the owner authorizes. It cannot send, delete or change email.

How the data is used

mailgate uses Gmail data only to provide its single feature: giving the owner's personal AI agent a filtered, redacted, read-only view of mail the owner has chosen to share (for example orders, bookings, discounts and appointments). Messages that fail the owner's filters, and security or financial mail, are not passed to the agent. Allowed messages are converted to plain text, sensitive values are redacted, and attachments are removed before the agent sees them.

Gmail data is not used for advertising, is not sold, and is not used to train or improve general-purpose AI or machine-learning models.

Storage

  • OAuth token. The refresh token is stored in a file on the owner's own machine, in a private data directory that the agent cannot read.
  • Email content. mailgate does not keep a copy of messages. It fetches them from Gmail when asked and holds them in memory only while handling the request.
  • Audit log. mailgate writes a local log of each request (time, tool name, search query, message IDs passed or blocked and the reason). It never records subjects, snippets or message bodies. The log stays on the owner's machine.

Sharing

mailgate shares filtered message text only with the AI agent that the owner configures and runs. Whatever that agent does with the text is governed by the agent's own terms and the owner's settings. mailgate itself does not transfer Google user data to the developer or to any other third party.

Limited Use

mailgate's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke mailgate's access at any time at myaccount.google.com/permissions. To delete everything mailgate stored, the owner deletes its data directory (the token file and audit log). Because there is no developer-run server, there is no other copy to delete.

Changes
